# Code of Conduct

## Our standard

PassThePhone is a social game, and the project should be just as welcoming as the product is intended to be.

Contributors are expected to:

- communicate respectfully;
- critique ideas and code rather than people;
- avoid harassment, discrimination, threats, or deliberate humiliation;
- respect privacy and do not post other people's personal information;
- keep issue and pull request discussions relevant and constructive.

## Scope

This applies to repository issues, pull requests, reviews, discussions, and other project spaces.

## Enforcement

Project maintainers may edit, hide, lock, or remove content and participation that violates these expectations.

For sensitive concerns, contact the repository owner privately rather than posting personal or security-sensitive details publicly.
